# الإنذارُ الكاذب — والصمتُ الكاذب
> متى تقرأ هذا الملف: حين يبدو إنذارٌ غريباً أو يتكرّر بالسبب نفسه، وقبل إغلاق أيّ إنذار، وحين يغيب إنذارٌ كان يُنتظر.

## 1) الإجراء
1. **تحقّق بمصدرٍ ثانٍ مستقلّ** قبل الرفع: قراءةٌ مباشرةٌ بعد دقيقة، أو أداةٌ أخرى (مثلاً `watch_once` ثمّ `archive_check` لشجرة، أو قضيّةُ GitHub ثمّ قراءةُ `/health/`).
2. **كاذب؟ أغلقه بسبب:** سطرٌ في الملخّص «أُغلق: <الرمز> — <السبب بدليله>». المصدر: ميثاق 0203 («كلُّ إنذارٍ بطاقةٌ في 0204 أو إغلاقٌ مسبَّب»).
3. **تكرّر بالسبب نفسه؟** بطاقةُ إصلاحٍ للأداة إلى «0204 · البوابة الموحّدة» (المصدر: الميثاق «إنذارٌ كاذبٌ متكرّر ← بطاقةُ إصلاحٍ للأداة»). المعنيّ: المايسترو لأدوات `delivery_manager_work/tools/` (يصون أدواتِه بنفسه — `flow_changelog.md` v2.3)، و«0801 · أتمتة الجدولة في الكود» لما نُقل إلى الشيفرة، وصاحبُ الوركفلو لما في `.github/workflows/`. «التكرار» غيرُ معرَّفٍ نصّاً؛ المعمولُ به هنا: المرّةُ الثانية بالسبب نفسه.
4. **لا تُسكت الأداةَ بنفسك** (لا تعديلَ لـ`thresholds.json` ولا للأداة): البطاقةُ تقترح الإصلاحَ ومعيارَ قبوله. العتباتُ «أوّليّةٌ تُضبط بعد ثلاثة أيّام قياس» — والضبطُ قرارُ المايسترو.
5. **احسب النسبة:** «نسبةُ الإنذارات الكاذبة» مؤشّرٌ في الميثاق — عُدَّ الكاذبَ والصادقَ في الملخّص اليوميّ.

## 3) صمتٌ كاذب — غيابُ الإنذار ليس سلامة
| الصمت | السبب | ما تفعله |
|---|---|---|
| لا قضيّةَ `uptime-failure` ولا `worker-heartbeat-failure` | الجدولةُ بأفضل جهد: قيس 09-25 نحو 7% من وتيرة فحص الإنتاج و4% من فحص العامل (تعليقا الوركفلوين) | اقرأ النقاطَ مباشرةً في كلّ جولة (المرجع 00 §3) |
| لا `main_red` | `watch_once` يسكت إن فشل `gh run list` (لا يطلق `gh_unavailable` إلّا لفشل `gh pr list`) | إن ظهر `gh_unavailable` أو شككتَ فاقرأ `gh run list` يدويّاً |
| مهمّةُ النسخ «ناجحة» (`LastTaskResult=0`) | السكربتُ القديم كان يكتم أخطاءه (`SilentlyContinue`) فمرّت أربعةُ أشهرٍ ونصفٌ بلا نسخ (05-13 ← 09-28) | عمرُ آخر ناتجٍ لا نتيجةُ المهمّة |
| `/health/` = 200 | لا يرى القوالب: حادثة 2026-09-17 أخضرُ ساعتين وكلُّ صفحةٍ 500 | `auth/login/` وقضيّةُ `deploy-failure` معه |
| لا تنبيهَ أمنيّاً | `watch_once` لا يقرأ الأمن أصلاً | `gh api` (المرجع 00 §6) |
| لا `orphan_tree` لشجرة جلسةٍ مسمّاة | يفحص الأشجارَ **بلا اسمٍ** في `session_names.json` وحدها | عملُ الجلسات المسمّاة يتابعه `session_load_v2` والمايسترو |
| حزمةُ git ونسخُ قاعدة الإنتاج | خارج `watch_once` | المرجع 00 §5 |

المصادر: `watch_once.py` و`branch_status.py`؛ `.github/workflows/monitor.yml` و`worker-heartbeat.yml` و`post-deploy-canary.yml`؛ `core/views_health.py`؛ `project_claude_backup_stale_lock_2026_09_28`؛ `feedback_audit_github_security_via_api`؛ القياساتُ المؤرَّخةُ أعلاه من تشغيلٍ قرائيٍّ يوم 09-28.

## 4) صيغةُ بطاقة إصلاح الأداة (إلى 0204)
- المشكلة: `<الرمز>` يطلق كاذباً لأنّ <السبب> (وقع <عدد> مرّات: <أوقاتٌ بالدوحة>).
- الأثر: <إنذاراتٌ مهدرة/ثقةٌ ضائعة/إنذارٌ حقيقيٌّ قد يُتجاهَل>.
- الملفّاتُ المظنونة: `delivery_manager_work/tools/watch_once.py` (الدالّة) أو `thresholds.json` أو الوركفلو.
- معيارُ القبول: الحالةُ الموصوفة لا تطلق، والحالةُ الصادقةُ المقابلةُ ما زالت تطلق (اختبارٌ في `tools/test_package.py` أو ما يقابله).
- المصدر `alert`، وأولويّةٌ وزمنُ بدءٍ مقترحان.

## أنماطٌ مضادّة
- إغلاقُ إنذارٍ «كاذب» بلا سببٍ مكتوبٍ ودليل.
- تكرارُ الإغلاق نفسِه يوماً بعد يوم بلا بطاقة إصلاح.
- رفعُ العتبة أو حذفُ الفحص محلّيّاً لإسكات الإنذار.
- اعتبارُ غياب القضايا الآليّة دليلَ سلامة.
- الحكمُ على شجرةٍ بعدّ الإيداعات، ثمّ اقتراحُ إزالتها.
