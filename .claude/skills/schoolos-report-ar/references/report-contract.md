# عقد التقرير الرسمي — SchoolOS

المرجع القياسي للطباعة موجود أيضاً في `web-design-mastery/references/reports-print.md`.
هنا العقد الرسمي المُلزِم لتقارير المنصة.

## القياسات

| العنصر | القيمة | ملاحظة |
|--------|--------|--------|
| مقاس الصفحة الافتراضي | A4 | A3 للجداول العريضة فقط |
| الهوامش | 20mm كل جهة | المنطقة الآمنة A4 ≈ 170×257mm |
| هامش التجليد (RTL) | 30mm يمين · 15mm يسار | للتجليد على اليمين |
| منطقة الترويسة | 22mm أعلى | شعار + وزارة + مدرسة + عنوان |
| منطقة التذييل | 14mm أسفل | سرّية + تاريخ + صفحة X من Y |
| خط العنوان H1 | 20pt Bold | — |
| خط عناوين الأقسام | 14pt Bold | — |
| خط بيانات الجداول | 10–11pt | لا تنزل تحت 9pt |

## محتوى الترويسة (على كل صفحة)
1. **يمين**: شعار دولة قطر (`assets/brand/qatar-emblem-2022.svg` في جذر المشروع).
2. **وسط**: «دولة قطر — وزارة التعليم والتعليم العالي» + اسم المدرسة الرسمي.
3. **يسار**: شعار/رقم المدرسة (إن وُجد).
4. سطر عنوان التقرير + العام الدراسي + الفصل.

## محتوى التذييل (على كل صفحة)
- تصنيف السرّية: «عام» / «داخلي» / «سرّي — للاستخدام الرسمي» (اختر حسب البيانات؛ أي تقرير فيه
  PII = سرّي على الأقل).
- التاريخ: ميلادي، وهجري عند التقارير الرسمية المُوقّعة.
- «صفحة X من Y».
- بصمة: «صُدر من منصة SchoolOS — <الطابع الزمني>».

## بنية المحتوى
```
عنوان التقرير (H1)
بيانات وصفية: الصف · المادة · المعلّم · تاريخ الإصدار
────────────────────────────────
الجدول/البيانات (رأس متكرّر على كل صفحة)
────────────────────────────────
الملخّص/الإجماليات (المعدّل، النسبة، عدد الناجحين…)
────────────────────────────────
التوقيعات: معلّم المادة · المنسّق · مدير المدرسة  (+ مكان الختم)
```

## التاريخ الهجري
الجدول يعتمد `hijri-converter` إن كان مثبّتاً، وإلا اكتب الميلادي فقط ولا تُقدّر الهجري يدوياً.
مثال العرض: «الأحد 6 يوليو 2026م / 20 محرّم 1448هـ».

## حالات حافة يجب معالجتها
- **بيانات فارغة**: reportlab (مسار xhtml2pdf) يفشل مع جدول فارغ — أظهر رسالة «لا توجد بيانات»
  بدل جدول فارغ (كما يفعل `reports/views.py` بحارس صريح).
- **أسماء طويلة**: `word-break` وعرض عمود مرن حتى لا تتكسّر البطاقة.
- **جدول أعرض من A4**: انتقل إلى A3، لا تُصغّر الخط تحت 9pt.
- **قطع طالب بين صفحتين**: `page-break-inside: avoid` على الصف/البطاقة.

## تصنيفات السرّية (طابق PDPPL)
| التصنيف | متى | مثال |
|---------|-----|------|
| عام | لا PII | إحصاء مجمّع بلا أسماء |
| داخلي | أسماء + بيانات تشغيلية | كشف درجات صف |
| سرّي — رسمي | PII/بيانات خاصة | تقرير صحي، كشف يحوي الرقم الشخصي |
