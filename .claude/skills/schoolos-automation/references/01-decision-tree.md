# شجرةُ القرار — أين تعيش الأتمتة

متى تقرأ هذا الملف: بعد الجرد وقبل كتابة سطر، لتختار المكان؛ وحين يقترح أحدٌ «مهمّةَ Claude مؤقّتة».

## السؤالُ الحاكم: ماذا يجب أن تلمس الأتمتةُ لتؤدّي عملها؟
المكانُ يُحدَّد بما تصل إليه كلُّ منصّة، لا بما هو أسهل كتابةً:
- beat على Railway يرى قاعدةَ المنصّة وRedis، ولا يرى جهازَ المالك ولا فروعه المحلّيّة.
- Actions يرى المستودعَ وواجهةَ GitHub وأسرارَ المستودع، ويعمل والجهازُ مطفأ، لكنّ جدولتَه بأفضل جهد.
- جدولةُ ويندوز ترى الأشجارَ و`~/.claude` وDocker المحلّيّ والذاكرة، وتعمل فقط والجهازُ قائم.
المصدر: `project_rk_metrics_native_collector_backlog`، `tests/test_monitoring_claims_are_honest.py`، `install_backup_task.ps1` (`StartWhenAvailable`).

```
0) أفيها حكمٌ أو قرارٌ أو تلخيصٌ لغويّ، أو اعتمادٌ أو دمجٌ أو نشر، أو مراسلةُ جلسة؟
   نعم ← لا تُؤتمت. تبقى عملَ جلسةٍ أو المالك؛ وأتمِت الجزءَ الحتميَّ حولها فقط (الجمع، العدّ، التنبيه).
1) أتحتاج قاعدةَ المنصّة أو Redis أو بياناتِ المدرسة أو إرسالَ إشعارٍ داخليّ؟
   نعم ← خدمةٌ + أمرُ إدارة + مهمّةُ Celery بمدخلٍ في beat_schedule.
2) أتحتاج المستودعَ أو واجهةَ GitHub أو فحصاً «من خارج Railway» (نسخٌ، مراقبةٌ خارجيّة)؟
   2أ) يُطلق بحدث (طلب دمج، دفعٌ إلى main، نشرٌ ناجح)؟ ← Actions على الحدث (الأوثق).
   2ب) قراءةٌ دوريّةٌ لعرضها في المنصّة؟ ← مجمِّعٌ في مركز قيادة الجودة عبر beat، لا Actions.
   2ج) عملٌ يوميٌّ أو أسبوعيٌّ يحتمل التأخّر وينتهي بقرارٍ واضح؟ ← Actions مجدول + إبلاغُ فشل.
3) أتحتاج جهازَ المالك: أشجار العمل، `~/.claude`، Docker المحلّيّ، ذاكرةَ الجهاز، `gh` المصادَق محلّيّاً؟
   نعم ← سكربتٌ خارج المستودع بجدولة ويندوز، بقفلٍ وملفِّ حالة.
4) لم ينطبق شيء، أو انطبق أكثرُ من فرع؟ ← قسّم العمل: كلُّ جزءٍ حيث بياناتُه، أو اسأل المايسترو.
```
وليس في أيّ فرعٍ «مهمّةُ Claude Code المجدولة» — ولا حتى مؤقّتاً. المصدر: D-50م، ميثاقُ 0801 (`boundaries`).

## قيودُ كلّ منصّةٍ التي تقلب القرار
| القيد | beat | Actions (جدول) | ويندوز |
|---|---|---|---|
| الوتيرةُ الموثوقة | دقيقةٌ فما فوق | لا ضمان: قيس 7% و4.4% من المتوقَّع (2026-09-25) | ما دام الجهازُ قائماً؛ `StartWhenAvailable` يلحق ما فات |
| إنذارُ الغياب (dead man's switch) | نعم بختمٍ يُقرأ عمرُه | لا يصلح وحدَه | لا؛ يقرؤه المراقبُ المحلّيّ |
| الوقت | قطر (`Asia/Qatar`) | UTC (الدوحة − 3) | منطقةُ الجهاز (Arab Standard Time اليوم) |
| الأسرار | متغيّراتُ Railway عبر `config()` | `secrets.*` و`vars.*` | متغيّراتُ بيئة المستخدم أو مخزنُه، لا ملفّ |
| مسارُ الشيفرة إلى العمل | الفلو كاملاً ثمّ نشرٌ بعد الدوام | الفلو كاملاً؛ التعديلُ بإذن المالك (مصنِّفُ الأذونات) | مستودعٌ خاصٌّ + تسجيلُ المهمّة بموافقة المالك |
| ما لا يُرى على 8500 | الجدولةُ نفسُها (beat غائب) | كلُّه | كلُّه |
المصادر: `shschool/celery.py`، `monitor.yml`، `worker-heartbeat.yml`، `feedback_doha_time_on_windows`، CLAUDE.md («المعاينةُ لا تعكس الإنتاجَ في… Sentry وbeat»)، `feedback_ask_before_push`.

## أمثلةٌ محسومة من المشروع
| الحالة | القرار | لماذا |
|---|---|---|
| انتهاءُ الصلاحيّات المؤقّتة | beat كلَّ دقيقة | بياناتُ القاعدة، ووتيرةٌ لا يحتملها Actions |
| النسخُ الاحتياطيّ للقاعدة | Actions يوميّاً | «خارج Railway» هو الغرض، ويحتمل التأخّر |
| حالةُ النسخ في لوحة الإدارة | beat يقرأ واجهة GitHub العامّة إلى الـcache | جسرٌ بلا سرٍّ ولا تعديلِ workflow (`core/backup_status.py`) |
| موتُ العامل | ختمٌ في Redis كلَّ 5 د + `/health/worker/` + فحصٌ خارجيٌّ ثانويّ | الغيابُ هو الإنذار؛ Sentry Crons مقعدٌ واحد مستنفد (`core/sentry_config.py`) |
| تحقّقُ ما بعد النشر | Actions على `deployment_status` | الحدثُ موثوقٌ والجدولُ لا |
| نسخُ `~/.claude` وحزمةُ git الليليّة | ويندوز | لا تراهما المنصّة ولا GitHub |
| RK1..RK3 | البعيدُ مجمِّعٌ في QCC، والمحلّيُّ تقريرُ ويندوز | الفروعُ المحلّيّةُ لا تُرى من Railway |
| المراقب `watch_once.py` | ويندوز | يقرأ ذاكرةَ الجهاز والأشجارَ و`gh` المحلّيّ |

## ما لا يُؤتمت أبداً (يبقى قراراً بشريّاً)
الاعتمادُ على 8500، والدمجُ والنشرُ وأوامرُ الإنتاج (للمالك وجلسة النشر)، وحذفُ الفروع والأشجار والأرشفة، وحسمُ أولويّةٍ أو تفسيرٍ ملتبس، وتسجيلُ بندٍ أو إغلاقُه في الخارطة (لـ«0701»). الأتمتةُ تُعِدّ المادّة (عدٌّ، تصنيفٌ، تنبيه) والقرارُ لصاحبه. المصادر: `feedback_approval_only_after_8500_preview`، `feedback_user_runs_the_merge`، `feedback_never_archive_without_order`، CLAUDE.md (الخارطة).

## أنماطٌ مضادّة
- اختيارُ Actions لأنّ «كتابةَ YAML أسرع» لعملٍ يحتاج القاعدة (يلزمه سرُّ قاعدةٍ علنيٌّ الموقع وبيئةٌ ثانية).
- مراقبٌ مجدولٌ في Actions يُعلَن «كلَّ N دقيقة» — ممنوعٌ بحارس `test_monitoring_claims_are_honest`.
- وضعُ منطقٍ يحتاج الجهازَ في beat ثمّ اكتشافُ أنّه لا يرى شيئاً (REP-10).
- أتمتةُ «القرار» نفسِه: دمجٌ آليٌّ عند الخضرة، أو إغلاقُ بندٍ بلا رقم طلب.
