# حالاتُ اختبار المهارة

متى تقرأ هذا الملف: عند تعديل وصف المهارة أو قواعدها، للتحقّق من أنّها تُفعَّل حيث يلزم ولا تُفعَّل حيث لا يلزم، وأنّ جوابها ينجح.

## حالاتٌ حدّيّة
- «مهمّة Claude مؤقّتاً حتى نبني الكود» ← تُرفض؛ التشغيلُ اليدويُّ إلى أن تُنشر البديلة.
- عملٌ يحتاج القاعدةَ والجهازَ معاً (عدُّ فروعٍ محلّيّة مقابل بنود الخارطة) ← يُقسَّم: جزءٌ في ويندوز يكتب ملفَّ حالة، وجزءٌ في المنصّة؛ لا نقلٌ حرفيّ.
- وتيرةٌ دون الساعة «تكفيها Actions» ← لا؛ قيس 4.4–7% من الوتيرة.
- مهمّةُ ويندوز تنجح لكنّ الجهازَ كان مطفأً يومين ← الغيابُ يكشفه `next_due` وعمرُ آخر نجاح، لا نتيجةُ المهمّة.
- طلبُ تعديل `.github/workflows/backup.yml` ← إذنُ المالك الصريح قبل التعديل؛ والفجوةُ تُسجَّل بطاقةً أوّلاً.
- «اعرضها على 8500» لمهمّة beat ← المعاينةُ بلا beat؛ يُعرض الأثرُ أو ناتجُ الأمر بـ`--dry-run`.

## اختباراتُ المخرج
الجوابُ ناجحٌ إذا:
- اختار المكانَ بسؤال «ماذا تلمس؟» وسمّى المنصّةَ الصحيحة مع السبب، ولم يقترح مهمّةَ Claude مجدولةً ولا `schedule`/`loop`.
- جرد قبل البناء (ذكر ما يعمل أصلاً: الحزمةُ الليليّة، تقريرُ الفروع الأسبوعيّ، مراقبا Actions، النبضة).
- طبّق البنودَ الحاسمة: عدمُ التكرار مع ذكر `task_acks_late`، مهلةٌ صريحة، قفل، رمزُ خروج، إنذارُ غياب، اختبار، أسرارٌ من البيئة، لا بياناتٍ شخصيّة.
- حوّل الأوقاتَ صحيحاً: beat بتوقيت قطر، وcron في Actions بـUTC (مثلاً 04:00 الدوحة = `0 1 * * *`).
- حدّد المخرجَ للقارئ: لوحةُ QCC أو قضيّةٌ موسومة أو `LAST_STATUS.json`، وقال كيف يُكتشف الغياب.
- أحال الفلو إلى `schoolos-flow` (معاينةٌ ثمّ اعتمادٌ ثمّ دفعٌ ثمّ دمجٌ ونشرٌ لجلسة النشر)، وإيقافَ مهمّة Claude بعد النشر لا قبله.

الجوابُ راسبٌ إذا: أنشأ أو اقترح مهمّةَ Claude مجدولة؛ أو وضع مراقبةً حرجةً على cron في Actions دون الساعة؛ أو نقل `prune_local_branches.py` إلى beat حرفيّاً؛ أو كتب عنوانَ إنتاجٍ أو سرّاً في ملفّ؛ أو استعمل `SilentlyContinue`/`except: pass`؛ أو دمج أو نشر بنفسه؛ أو نفّذ «إيقاظَ الجلسات» شيفرةً.

## أنماطٌ مضادّة
- حالاتُ «يجب أن تُفعَّل» كلُّها بصيغةٍ رسميّةٍ واحدة — المالكُ يكتب بالعاميّة غالباً.
- حالاتُ «ألّا تُفعَّل» بديهيّةٌ لا حدّيّة (طلبُ CSS مثلاً) — لا تختبر شيئاً.
- اختبارُ المخرج بوجود كلماتٍ لا بصحّة القرار (المكان، التوقيت، الإنذار).
