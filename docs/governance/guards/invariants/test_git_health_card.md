| **بطاقةُ صحّة Git في الإدارة (REP-10 ب)** | `test_git_health_card` | بطاقةُ «صحّة Git» تقرأ RK1..RK3 من الخارطة (آخرَ قراءةٍ مسجَّلةً وعمرَها) لا من git — الصورةُ بلا git والإنتاجُ بلا `.git` — فلا تدّعي قياساً حيّاً: «غير مقيس» أصفر لا أخضر، ومؤشّرٌ بلا قراءةٍ أو بلا تاريخٍ يُحسب فيصفرّ، والعمرُ من **أقدم** قراءةٍ معلومةً لا إنذاراً (القياسُ يدويٌّ عند الطلب — قرارُ 0701، 2026-09-29، بعد D-60م: فلا تصفرّ البطاقةُ ولا تحمرّ بالعمر)، وبُعدُ RK2 (عملٌ فريدٌ بنسخةٍ وحيدة) عن هدفه أحمرُ لا أصفر (فقدانٌ لا يُسترجع)؛ والنصُّ أرقامٌ وتسمياتٌ وتواريخُ فقط (PDPPL). ثماني طفراتٍ تُسقط الاختبار؛ وعددُ البطاقات في الرئيسيّة يُقارَن بـ`BUILDERS` لا برقمٍ ثابت |
