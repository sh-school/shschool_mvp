|---|---|---|
| **مراجعُ `{% static %}` موجودة** | `test_static_references_exist` | كلُّ `{% static '…' %}` حرفيٍّ في قوالب المنصّة يشير إلى ملفٍّ في `static/` أو `*/static/` (عدا حزم الطرف الثالث: admin وdebug_toolbar…)؛ وإلّا يرمي الإنتاجُ (manifest صارم) `Missing staticfiles manifest entry` فتسقط الصفحةُ كلُّها بـ500 ولا يُكشف في التطوير (`USE_FINDERS`). أُضيف بعد أن كاد حذفُ `schedule-export.js` في طلبٍ وبقاءُ سطرِ تحميله في قالبٍ أضافه طلبٌ آخر يُسقطان «جداول المعلّمين»؛ فيُمسك المرجعَ اليتيمَ قبل الدمج |
