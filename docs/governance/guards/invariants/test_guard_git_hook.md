| **حارسُ الغيت في الـhook (REP-19، RD8)** | `test_guard_git_hook` | `.claude/hooks/guard_git.py` (يشغّله `.claude/hooks/guard_git.sh` من `PreToolUse` لـBash وPowerShell في `.claude/settings.json`) يحجب في كلّ جلسةٍ ما يحظره بروتوكولُ المحادثات المتوازية: `add -A` و`add .` بلا مسارات، و`commit -a`، و`stash`، والدفعَ إلى main، و`--force` و`+refspec`، وحذفَ مرجعٍ بعيد، والدفعَ الجماعيَّ (`--all`/`--tags`) ولمرجعٍ تحت `archive/`، و`--no-verify` و`SKIP=`، و`reset --hard`، و`branch -D`، و`tag -d`، و`update-ref -d`، وإعادةَ كتابة التاريخ ومحوَ الكائنات، و`clean -f`، و`checkout`/`restore .`، و`prune_local_branches --apply`. **يفكّ ما يلتفّ به الأمر** — `bash -c` وenv وsudo وxargs و`$(…)` وأسماءُ git المستعارة و`& git` في PowerShell و`-EncodedCommand` — **ولا يحلّل** أجسامَ heredoc ولا نصَّ الاقتباس (رسالةُ إيداعٍ تذكر `git push --force` تمرّ)، **ولا تسري قواعدُه المحلّيّة على مجلّدٍ خارج المستودع** (مستودعُ الوثائق). قيس على نحو 20 ألف أمر git حقيقيّ من نصوص الجلسات فلم يُحجب سليمٌ (`git add -A <مسارات>` و`branch -d` وحذفُ `refs/tmp/` وإزالةُ شجرةٍ مؤقّتة مسموحة). **التجاوزُ** بادئةً للأمر: `GUARD_GIT_ALLOW='<إذنُ المالك وتاريخُه>'` (10 أحرفٍ فأكثر، ويُسجَّل خارجَ المستودع في `~/.claude/logs`). **حدُّه:** شبكةُ أمانٍ ضدّ الحوادث لا صندوقٌ معزول — لا يرى ما في سكربتٍ يُشغَّل ولا متغيّراً غيرَ محلول ولا صدفةَ المالك في طرفيّته، فلا يُغني عن إعدادات git المشتركة (REP-11). ثلاثون طفرةً تُسقط الاختبار |
