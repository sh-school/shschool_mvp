# مختبر جودة الجدول (Schedule Quality Lab)

**القرار:** 2026-09-04 — القياس قبل تعديل المولّد. رقم الجودة الواحد `quality_score` لا يقول لماذا جدول 96 أفضل من 94، فصار لكلّ جدول (مسودّة أو حيّ) 22 مؤشراً باسم وتعريف ووحدة واتّجاه، تُقارَن بأساس مرجعيّ محفوظ.

## أين
- `operations/schedule_lab.py` — الحساب (`ScheduleLab`)، التعريفات (`CATALOG`)، المقارنة (`compare`)، التخزين (`store_metrics`).
- `manage.py schedule_lab` — قياس ومقارنة وحفظ أساس من سطر الأوامر.
- `manage.py seed_subject_pedagogy` — يضبط «طبيعة المادّة» من رمزها.
- `ScheduleGeneration.metrics` — المؤشرات تُحسب عند انتهاء التوليد (`tasks.py`) وعند الاعتماد وتُحفظ.
- `ScheduleBaseline` — الأساس المرجعيّ (مدرسة، عام، اسم، مؤشرات).
- شاشة الجدولة الذكيّة — تحت كلّ توليد صفّ «المؤشرات» مطويّ يعرض القيمة والأساس والفرق (أخضر أفضل، أحمر أسوأ).

## المؤشرات
| المجموعة | المعرّف | التعريف | الأفضل |
|---|---|---|---|
| الصلاحية | `validity.hard_conflicts` | معلّم في خانتين، شعبة بمادّتين بلا مجموعة متوازية، تداخل بالساعة، تماسّ بين طابقين، تفريغ منتهَك، مورد فوق سعته | 0 |
| | `validity.completeness` | الحصص الموضوعة ÷ حصص التوزيعات | 100% |
| | `validity.uncovered_days` | معلّمون لهم يوم فارغ بلا تفريغ ومواضعهم تبلغ أيّامهم (المزدوجة موضع واحد) | 0 |
| يوم المعلّم | `teacher.gap_weighted_avg` | لكلّ يوم Σ(طول الفراغ)² ÷ حصص اليوم، متوسّطاً على المعلّمين؛ فراغ الحصّتين أربعة أضعاف فراغ الحصّة | أقلّ |
| | `teacher.gap_weighted_max` | أسوأ يوم لمعلّم، بالاسم | أقلّ |
| | `teacher.compactness` | (آخر حصّة − أوّل حصّة + 1) ÷ حصص اليوم؛ 1.0 مثاليّ | أقلّ |
| | `teacher.run_avg` / `run_breaches` | أطول تتابع في اليوم، وأيام تجاوزت سقف المعلّم (الشخصيّ أو العامّ 1) | أقلّ |
| | `teacher.weekly_imbalance` | الانحراف المعياريّ لحصص الأيام المتاحة (نصاب ≥ 5) | أقلّ |
| | `teacher.transitions_avg` / `transitions_max` | انتقالات بين نطاقين مختلفي الجرس في اليوم | أقلّ |
| العدالة | `fairness.edge_cv` | معامل اختلاف نسبة (الأولى + السابعة) ÷ النصاب بين المعلّمين | أقلّ |
| | `fairness.stress` | (الفراغ الموزون + الأطراف + تجاوزات التتابع + تفاوت الأيام) ÷ النصاب؛ يُعرض أعلى خمسة بالاسم | أقلّ |
| | `fairness.preference_satisfaction` | نسبة قواعد التفضيلات المحقّقة (سقف يومي، تتالٍ، فراغ، يوم مفضّل) | أعلى |
| المادّة والشعبة | `subject.pattern_match` | مطابقة نمط الأيام للمثاليّ: 5 = 1-1-1-1-1، 6 = 2-1-1-1-1، 7 = 2-2-1-1-1، والمزدوجة المطلوبة [2] | أعلى |
| | `subject.same_period_max` | أكبر تكرار لرقم حصّة واحد للمادّة في الشعبة، متوسّطاً | أقلّ |
| | `subject.heavy_morning` | الموادّ «الثقيلة» في الحصص 1–4 | أعلى |
| | `subject.activity_afternoon` | موادّ «النشاط» في الحصص 5–7 | أعلى |
| | `class.heavy_streak_days` | أيام شعبة فيها ثلاث ثقيلات متتالية | أقلّ |
| | `class.maths_late` | الرياضيات في السادسة والسابعة | أقلّ |
| الموارد | `resources.utilization` | لكلّ مورد: الخانات المستعملة ÷ (السعة × 35) | معلومة |
| | `resources.saturated_slots` | خانات بلغ فيها المورد سعته | أقلّ |

«طبيعة المادّة» حقل على `Subject` (ثقيلة / نشاط / عادية) يُضبط من لوحة الإدارة، ويُبذر من الرمز: MAT SCI GSC PHY CHM BIO ARA ENG ثقيلة، PE ART TECH IT CS LFS نشاط.

## التشغيل
```bash
python manage.py seed_subject_pedagogy
python manage.py schedule_lab --live --save-baseline "أساس 2026-09"   # مرّة واحدة على الإنتاج
python manage.py schedule_lab --live --compare baseline
python manage.py schedule_lab --generation <id> --compare live
python manage.py schedule_lab --generation <id> --store                # لتوليد قديم بلا مؤشرات
```
