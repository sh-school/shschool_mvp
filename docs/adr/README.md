# سجلّات القرارات المعماريّة (ADR)

كلّ قرار معماريّ يغيّر بنية المنصّة أو يُدخل اعتماداً أو يفتح سطحاً جديداً يُكتب هنا قبل الشيفرة.

## القواعد

- اسم الملفّ: `NNNN-عنوان-بالإنجليزيّة.md`، والترقيم متسلسل لا يُعاد استعماله.
- الحالات: مقترح ← مقبول ← (مُهمَل | مُستبدَل بـ ADR-NNNN).
- القرار المقبول لا يُعدَّل مضمونه. التغيير يكون بقرار جديد يستبدله، ويُحدَّث سطر الحالة في القديم فقط.
- كلّ واقعة عن الشيفرة تُذكر بموضعها، لتُفحص عند المراجعة.
- لا بيانات إنتاج ولا أسماء أشخاص: المستودع عامّ.
