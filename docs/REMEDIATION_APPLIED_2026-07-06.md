## 3. خطوات النشر المطلوبة (قبل الإنتاج)

```bash
# 1) ترحيلات جديدة: token_blacklist (JWT) + notifications 0007 (DLQ)
python manage.py migrate

# 2) تأكيد عدم وجود فروق models غير مُرحَّلة
python manage.py makemigrations --check --dry-run

# 3) بوابة الجودة + اختبارات الإصلاحات
ruff check . && mypy . && pytest tests/test_remediation_2026_07_06.py -q

# 4) تدوير المفاتيح: اختبر على نسخة من الإنتاج قبل إزالة المفتاح القديم من FERNET_OLD_KEYS
python manage.py rotate_fernet_key
```
