# أيقونات التطبيق

أيقوناتُ التطبيق كلُّها في **`static/icons/v7/`** — مجلّدٌ مرقَّم لا يُستبدل ملفٌّ فيه: Chrome 144+ لا يعيد تنزيلَ أيقونةٍ تغيّر محتواها ورابطُها واحد،
وiOS يحفظ الأيقونةَ لحظةَ الإضافة. فتغييرُ الأيقونة = مجلّدٌ جديد (`v7`) + تحديثُ `ICON_VERSION` في `build_app_icons.py` + المانيفستَين
(`id` فيهما لا يتغيّر أبداً: `/` و`/parents/`) + `base.html` و`login.html` وصفحاتُ الخطأ و`admin/base_site.html` و`pwa/offline_global.html`
+ `notifications/tasks.py` وأيقونةُ الإشعار في `parents/pwa/sw.js` + رفعُ أسماء الذاكرة في عاملَي الخدمة (`schoolos-global-vN` و`schoolos-parents-vN`)
+ `VERSION` في `static/js/icon-update-notice.js` (بطاقةُ «تغيّرت أيقونة التطبيق» لمن ثبّت قبل التغيير). ومجلّداتُ الأيقونات السابقة (`v2/` إلى `v6/`)
تبقى على القرص لتطبيقٍ مثبَّتٍ قديمٍ أو ذاكرةِ عاملِ خدمةٍ قديم، **ولا مرجعَ إليها في الشيفرة** (`test_no_reference_to_a_superseded_icon_folder`).

| الملف | الغرض |
|---|---|
| `icon-192.png` و`icon-512.png` | الرمزُ الكاملُ العنّابيّ (الشين بمضماره) على لوحٍ كريميٍّ مدوَّر الزوايا (v7، إذنُ المالك 2026-11-16؛ كان شفّافاً فخفت على الشريط الداكن) — `purpose: any`، والإشعارات |
| `icon-maskable-192.png` و`icon-maskable-512.png` | `purpose: maskable` — أندرويد يقصّها في قناعه؛ صندوقُ الرمز بمضماره داخل الدائرة الآمنة (نصفُ قطرها 40% من الضلع) |
| `apple-touch-icon.png` (180) | الشاشة الرئيسية في iOS — معتمة، فالشفّافُ يُملأ بالأسود |
| `favicon.png` و`favicon.ico` | تبويبُ المتصفّح — مربّعٌ بزوايا مدوَّرةٍ (22%) شفّافةٍ والرمزُ العنّابيّ يملأ ارتفاعَه؛ كلُّ مقاسٍ في الـico يُرسم بحجمه |
| `favicon.svg` و`favicon-dark.png` | التبويبُ الداكن (طلبُ المالك 2026-11-16): الـSVG يبيضّ بـ`prefers-color-scheme: dark` داخله، والـPNG الأبيضُ لمن لا يدعمه. Safari لا يلتزم بـ`media` على الأيقونة ولا بـSVG، والمتصفّحاتُ تتبع سمةَ النظام لا سمةَ المنصّة |
| `badge-72.png` | شارةُ الإشعار — الرمزُ كلُّه أبيضَ على شفّاف |

كلُّها مولَّدةٌ بأمرٍ واحدٍ من أصلَي الرمز الكامل `static/brand/shahaniya-mark-white.svg` (المعتمة والشارة) و`shahaniya-mark.svg` (الشفّافة)؛ أمرُ المالك 2026-11-16: كلُّ الأيقونات شينٌ وحوله المضمار فلا تُعدَّل باليد:

```bash
python manage.py build_app_icons
```

## شعارُ الوزارة للمخرجات وحدَها

شعارُ الوزارة الأصليّ ملفُّه `core/assets/ministry_logo.png` **خارجَ `static/`** عمداً فلا رابطَ يخدمه. يظهر أعلى وسط ترويسةِ
PDF والطباعة وExcel والمصدَّر واسمُ المدرسة تحته وسطاً، بلا سطر نصّ الوزارة، ولا يظهر في المنصّة أبداً
(`tests/test_ministry_logo_exports_only.py`). و`tests/test_brand_emblem.py` يحرس الأيقوناتِ على الشريحة الداكنة وداخلَ الدائرة الآمنة،
وما بقي في `static/brand/` (توقيعُ المطوّر والشعاران).
