# أيقونات التطبيق

أيقوناتُ التطبيق كلُّها في **`static/icons/v2/`** — مجلّدٌ مرقَّم لا يُستبدل ملفٌّ فيه: Chrome 144+ لا يعيد تنزيلَ أيقونةٍ تغيّر محتواها ورابطُها واحد،
وiOS يحفظ الأيقونةَ لحظةَ الإضافة. فتغييرُ الأيقونة = مجلّدٌ جديد (`v3`) + تحديثُ `ICON_VERSION` في `build_app_icons.py` + المانيفستَين
(`id` فيهما لا يتغيّر أبداً: `/` و`/parents/`) + `base.html` و`login.html` وصفحات الخطأ + `notifications/tasks.py` وقائمةُ الذاكرة المسبقة وأسماءُ الذاكرة
في عمّال الخدمة + `VERSION` في `static/js/icon-update-notice.js` (بطاقةُ «تغيّرت أيقونة التطبيق» لمن ثبّت قبل التغيير).

| الملف | الغرض |
|---|---|
| `icon-192.png` و`icon-512.png` (و`.webp`) | حرفُ «ش» أبيضُ على العنّابيّ — `purpose: any`، والإشعارات |
| `icon-maskable-192.png` و`icon-maskable-512.png` | `purpose: maskable` — أندرويد يقصّها في قناعه |
| `apple-touch-icon.png` (180) | الشاشة الرئيسية في iOS — معتمة، فالشفّافُ يُملأ بالأسود |
| `favicon.png` وملفُّ `../brand/favicon.ico` | تبويبُ المتصفّح |
| `badge-72.png` | شارةُ الإشعار — «ش» بيضاء على شفّاف |

كلُّها مولَّدةٌ بأمرٍ واحدٍ من الخطّ (Tajawal Bold) فلا تُعدَّل باليد:

```bash
python manage.py build_app_icons
```

## لا شعارَ وزارةٍ

أُزيل شعارُ الوزارة من المنصّة كلِّها بقرار المالك (W-20261011-012، D-386م): لا في الواجهة ولا في الطباعة ولا PDF ولا Excel ولا
الأيقونات. فالهويّةُ البصريّةُ لأيقونة التطبيق حرفُ «ش» أبيضُ على العنّابيّ #8A1538 (`core/brand.py:MAROON`). وما بقي في `static/brand/`
توقيعُ المطوّر (`azkia-logo.svg` و`sufyan-logo.png`). `tests/test_brand_emblem.py` يحرس ذلك، و`tests/test_pwa_install.py` يحرس
أنّ الحرفَ داخل الدائرة الآمنة للأيقونات القابلة للقصّ.
