# أيقونات التطبيق

أيقوناتُ التطبيق كلُّها في **`static/icons/v4/`** — مجلّدٌ مرقَّم لا يُستبدل ملفٌّ فيه: Chrome 144+ لا يعيد تنزيلَ أيقونةٍ تغيّر محتواها ورابطُها واحد،
وiOS يحفظ الأيقونةَ لحظةَ الإضافة. فتغييرُ الأيقونة = مجلّدٌ جديد (`v5`) + تحديثُ `ICON_VERSION` في `build_app_icons.py` + المانيفستَين
(`id` فيهما لا يتغيّر أبداً: `/` و`/parents/`) + `base.html` و`login.html` وصفحاتُ الخطأ و`admin/base_site.html` و`pwa/offline_global.html`
+ `notifications/tasks.py` وأيقونةُ الإشعار في `parents/pwa/sw.js` + رفعُ أسماء الذاكرة في عاملَي الخدمة (`schoolos-global-vN` و`schoolos-parents-vN`)
+ `VERSION` في `static/js/icon-update-notice.js` (بطاقةُ «تغيّرت أيقونة التطبيق» لمن ثبّت قبل التغيير). ومجلّداتُ الأيقونات السابقة (`v2/` و`v3/`)
تبقى على القرص لتطبيقٍ مثبَّتٍ قديمٍ أو ذاكرةِ عاملِ خدمةٍ قديم، **ولا مرجعَ إليها في الشيفرة** (`test_no_reference_to_a_superseded_icon_folder`).

| الملف | الغرض |
|---|---|
| `icon-192.png` و`icon-512.png` | «قلمٌ وشعلة» على شريحةٍ داكنةٍ محايدة — `purpose: any`، والإشعارات |
| `icon-maskable-192.png` و`icon-maskable-512.png` | `purpose: maskable` — أندرويد يقصّها في قناعه؛ صندوقُ القلم داخل الدائرة الآمنة (نصفُ قطرها 40% من الضلع) |
| `apple-touch-icon.png` (180) | الشاشة الرئيسية في iOS — معتمة، فالشفّافُ يُملأ بالأسود |
| `favicon.png` و`favicon.ico` | تبويبُ المتصفّح — مربّعٌ بزوايا مدوَّرةٍ (22%) شفّافةٍ والقلمُ يملأ ارتفاعَه؛ كلُّ مقاسٍ في الـico يُرسم بحجمه |
| `badge-72.png` | شارةُ الإشعار — القلمُ كلُّه أبيضَ على شفّاف |

كلُّها مولَّدةٌ بأمرٍ واحدٍ من الأصل `static/brand/schoolos-pen.svg` فلا تُعدَّل باليد:

```bash
python manage.py build_app_icons
```

## الشعاران المعتمدان (قرارُ المالك 2026-10-14، W-20261014-009)

- **الكاملُ بالكتاب** `static/brand/schoolos-full.svg`: شعارُ المنصّة في الدخول والترويسة وصفحات الخطأ وما دون الاتصال ولوحة الإدارة،
  على شريحةٍ داكنةٍ محايدةٍ (`core.brand.DARK["SURFACE"]`) لا على العنّابيّ لأنّ ألوانَه عنّابيّةٌ داكنة.
- **المشتقُّ «قلمٌ وشعلة»** `static/brand/schoolos-pen.svg`: الفايكون وأيقوناتُ PWA وشارةُ الإشعار، يحلّ محلّ حرف «ش» (v3).

## شعارُ الوزارة للمخرجات وحدَها

شعارُ الوزارة الأصليّ ملفُّه `core/assets/ministry_logo.png` **خارجَ `static/`** عمداً فلا رابطَ يخدمه. يظهر أعلى وسط ترويسةِ
PDF والطباعة وExcel والمصدَّر واسمُ المدرسة تحته وسطاً، بلا سطر نصّ الوزارة، ولا يظهر في المنصّة أبداً
(`tests/test_ministry_logo_exports_only.py`). و`tests/test_brand_emblem.py` يحرس الأيقوناتِ على الشريحة الداكنة وداخلَ الدائرة الآمنة،
وما بقي في `static/brand/` (توقيعُ المطوّر والشعاران).
